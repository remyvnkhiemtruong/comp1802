# Aquarium

A full-screen aquarium animation built with pure HTML and CSS — no JavaScript required.

## Preview

Open `index.html` in any modern browser. No installation needed.

## Features

- Animated fish school, goldfish, shark, sea turtle, and three divers
- Fully responsive, fills the entire viewport
- Zero dependencies — HTML & CSS only
